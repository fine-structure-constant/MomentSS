# 留白拼图

一个完全在浏览器本地运行的旅行照片工作台。它把长图排版、朋友圈中部方形封面控制，以及 4 / 6 / 9 图切分放在同一个响应式 Web 应用里。

## 功能

- **长图排版**：右侧以“资源 / 图层 / 调整”分开工作；资源支持批量导入、关键字搜索（同时匹配名称与文字内容）、按类型筛选（全部 / 图片 / 文字 / 长图）和 2 / 3 / 4 列切换，筛选与列数会被记住。文字可插入到任意两层之间（悬停图层间隙时出现入口），追加到末尾由资源面板的文字卡片完成；把一层与紧邻的下一层并排成一行，只需悬停该层点“向下并排”（下一层不是独立图片时不出现该入口），行内可互换左右。每张图片仍可独立调整内部缩放、焦点与裁切；双图行可调整行高、间距并随时拆开。
- **统一的资源列表与详情卡片**：图片、文字卡片和已保存长图混排在同一个列表里，用类型筛选区分，不再分成两个区块。列表项只有缩略图、一个主操作（图片与文字卡片为“加入画布”，长图为“继续排版”，封面组合为“调整封面”）和一个“查看”按钮，带文字的资源会在缩略图下方显示文字摘要。点击缩略图即选中该资源，会自动定位到画布上由它派生的图层并切到“调整”栏目；点“查看”则打开详情卡片，给出更大的预览、名称 / 类型 / 尺寸 / 图层数 / 保存时间等元信息，以及加入画布或继续排版、设置封面、重命名、删除和 PNG / JPG 下载。
- **记住上次样式**：新增文字卡片会沿用上一次编辑过的字体、字号、颜色、对齐与行距，图片文字同样记住上次的样式与位置；设置保存在当前浏览器，只影响之后新插入的对象，不改动已有图层。
- **图片文字容器**：在独立画面编辑器中自由拖动，支持字体、字号、颜色、粗斜体、对齐、角度和宽度；底色进一步支持透明度、内边距、边框类型/粗细/颜色和圆角，预览与最终导出使用同一旋转几何。编辑器以草稿方式工作，关闭或按 Escape 放弃改动，只有点“完成”才写入图层；取景框与长图调整栏使用同一套裁切控件。
- **Emoji 输入**：文字卡片和图片文字均可从内容框旁打开 Emoji 面板，按分类浏览、中英文搜索或选择最近使用的表情。在光标处插入或替换选中文字，之后可直接继续输入；组合表情按完整字素换行，并随文字保存、导出。面板使用内置常用清单，也支持粘贴或系统键盘输入其他 emoji；外观取决于设备字体。
- **封面置中**：选择已保存的结构化长图和一张图片，调整方形取景、完整图层之间的插入位置、封面周围留白及背景色。系统自动平衡顶部或底部留白，使指定封面占据长图中心方形区域；原图层不被切开。封面结果保存到资源后导出。
- **4 / 6 / 9 图切分**：分别按 2×2、3×2、3×3 切成正方形图片，并依照从左到右、从上到下的顺序编号下载。
- **本地草稿**：长图项目通过 IndexedDB 保存在当前浏览器；图片不会上传到应用服务器。
- **独立资源库**：已导入图片与文字资源可单项删除、重复加入画布；重命名与删除都在详情卡片里完成，删除前会确认，误删可在提示条上点“撤销”还原。文字内容、字体样式及图片文字的位置、底色、边框、裁切参数自动保存到对应资源，再次加入可继续编辑。清空草稿保留资源，删除资源保留已排版图层；已有副本仍独立。
- **保存与导出**：资源栏统一添加内容、查看资源和下载 PNG / JPG；文字资源按已编辑格式导出，图片资源保留裁切及图片文字。长图界面通过“保存长图”生成独立结构化快照；从已保存长图继续排版时，底部会提示当前正在编辑哪一张，可选择“更新这张长图”或“另存为新长图”，避免每次另存都堆出一份新快照。清空草稿和删除原素材不影响已保存长图或封面。
- **苹果照片导入**：资源导入和切图支持 HEIC / HEIF / HIF，以及 HEIC / HEIF 序列文件的首张静态图；封面直接选择资源中的图片。导入时在浏览器本地转换为 PNG，保留文件名及原始像素尺寸，之后可添加文字、裁切、保存资源和导出。转换后的资源不包含原文件的拍摄元数据、动态内容或 HDR 信息。解码库首次遇到 HEIF 才加载，无需服务器或第三方转换服务。
- **交互预览**：长图由结构化排版展示，可点击图片、文字块或双图行放大调整；整体画布设置放在图层栏目，调整顶部显示当前操作对象。
- **响应式界面**：桌面采用独立滚动的画布与属性区域；手机长图排版采用画布优先流程，封面先选择资源，再查看结果与调整参数。
- **三语界面**：支持简体中文、繁体中文和英语；语言选择会保存在当前浏览器。

> 微信客户端的缩略图规则可能随版本变化。本项目以“长图中部正方形”为工作模型，不承诺第三方客户端的永久一致性。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:4173/`。

## 验证与构建

```bash
npm test
npm run build
```

生产文件输出到 `dist/`，可部署到任意静态站点托管服务。

## 修改界面文案

所有界面文案都集中在三个语言文件中，键名保持一致，改字不需要进入业务组件：

- `src/i18n/locales/zh-CN.ts`：简体中文，也是完整键名的类型来源。
- `src/i18n/locales/zh-TW.ts`：繁体中文。
- `src/i18n/locales/en.ts`：英语。

动态内容使用 `{{count}}`、`{{date}}` 一类占位符。TypeScript 会在构建时检查三份语言是否缺少或多出键名；修改后运行 `npm test` 和 `npm run build` 即可验证。

## 自动部署到服务器

项目已提供 push 到 `main` 后自动构建并发布静态部署包的 GitHub Actions。
Rocky Linux 服务器主动下载新版本，通过现有 Nginx 和 Cloudflare Tunnel 提供服务。
应用目录为 `/home/rocky/data/service/momentss`，域名为 `momentss.renschekhe.site`。
首次安装命令、配置、权限设置与回滚步骤见 [部署说明](./deploy/README.md)。

## 隐私与浏览器说明

- 所有图片解码、Canvas 合成和下载都在浏览器中完成。
- 草稿、导入资源与已保存长图仅保存在当前浏览器的 IndexedDB；清除站点数据会删除这些内容。
- 批量下载 4 / 6 / 9 张切图时，浏览器可能要求允许多个文件下载。
- 超大图片会在导出时按浏览器画布安全范围缩放，并在界面中提示。
