# 留白拼图

一个完全在浏览器本地运行的旅行照片工作台。它把长图排版、朋友圈中部方形封面控制，以及 4 / 6 / 9 图切分放在同一个响应式 Web 应用里。

## 功能

- **长图排版**：批量导入图片、拖动或按钮排序、在任意位置插入文字卡片，也可在独立画面编辑器中创建可拖动的图片文字框；支持字体、字号、颜色、粗斜体、对齐、角度、宽度和自由位置调整。
- **封面置中**：从长图中裁出正方形封面，并把它插入长图的垂直中部，以中部正方形作为朋友圈缩略图的工作预览。
- **4 / 6 / 9 图切分**：分别按 2×2、3×2、3×3 切成正方形图片，并依照从左到右、从上到下的顺序编号下载。
- **本地草稿**：长图项目通过 IndexedDB 保存在当前浏览器；图片不会上传到应用服务器。
- **响应式界面**：桌面采用互不干扰的顺序、画布、属性三栏滚动区，手机改为画布优先的纵向流程。

> 微信客户端的缩略图规则可能随版本变化。本项目以“长图中部正方形”为工作模型，不承诺第三方客户端的永久一致性。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:4173/`。

## 验证与构建

```bash
npm test
npm run build
```

生产文件输出到 `dist/`，可部署到任意静态站点托管服务。

## 隐私与浏览器说明

- 所有图片解码、Canvas 合成和下载都在浏览器中完成。
- 长图草稿仅保存在当前浏览器的 IndexedDB；清除站点数据会删除草稿。
- 批量下载 4 / 6 / 9 张切图时，浏览器可能要求允许多个文件下载。
- 超大图片会在导出时按浏览器画布安全范围缩放，并在界面中提示。
